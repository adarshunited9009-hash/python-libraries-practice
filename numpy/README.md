# NumPy Practice

These are the NumPy examples I've practised so far.

## Files

### 01_array_creation.py

Creates an array containing `1, 2, 3, 4, 5`, then multiplies every value by 3. It also prints the array's type.

### 02_array_dimensions.py

Creates a 2D array with three rows and three columns. The `ndim` attribute prints `2`, because the array has two dimensions.

### 03_three_dimensional_array.py

Creates a 3D array. It prints the array, its number of dimensions, and its shape. The shape is `(2, 2, 3)`: two blocks, two rows in each block, and three values in each row.

## Run a program

Install NumPy if you haven't already:

```bash
python -m pip install numpy
```

From the main repository folder, run for example:

```bash
python numpy/03_three_dimensional_array.py
```
